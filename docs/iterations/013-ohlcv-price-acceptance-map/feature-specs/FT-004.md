# FT-004: 区域划分插件框架

## 基本信息
- **Feature ID**: FT-004
- **功能名称**: 区域划分插件框架
- **对应需求**: REQ-005
- **功能类型**: orchestration
- **优先级**: P0
- **状态**: draft

---

## D-01: 功能标识
- **全局唯一 ID**: FT-004
- **入口类型**: 区域服务编排
- **入口路径**: `region_partition_service`

## D-02: 输入规格
| 参数名 | 类型 | 必填 | 约束 | 默认值 | 示例 |
|--------|------|------|------|--------|------|
| micro_axis | object | 是 | 必须来自 FT-002 | - | 100 个价格单元 |
| partition_mode | string | 是 | 一期支持 `adaptive_volatility`、`equal_width` | - | `adaptive_volatility` |
| partition_config | object | 否 | 与插件模式匹配 | `{}` | `{ "group_size": 5 }` |

## D-03: 前置条件
- [ ] 底层价格轴已构建
- [ ] 区域插件模式已明确
- [ ] 对应插件所需配置已满足最小字段要求

## D-04: 正常输出
- 返回一组连续区域定义
- 每个区域必须给出 `region_id`、`lower_bound`、`upper_bound`
- 区域集合必须完整覆盖历史价格范围且彼此不重叠
- 上层聚合服务可无差别消费不同插件的区域结果

## D-05: 异常行为
| 错误码 | 触发条件 | 错误消息 |
|--------|---------|---------|
| UNSUPPORTED_PARTITION_MODE | 请求未实现的区域模式 | 当前版本不支持该区域划分模式 |
| INVALID_PARTITION_CONFIG | 插件配置不合法 | 区域划分参数非法，无法生成完整区域 |
| REGION_GAP_DETECTED | 区域未覆盖完整价格范围 | 区域划分结果存在缺口 |
| REGION_OVERLAP_DETECTED | 相邻区域发生重叠 | 区域划分结果存在重叠 |

## D-06: 边界值
- 区域数必须大于等于 1
- 第一段区域必须覆盖 `price_min`
- 最后一段区域必须覆盖 `price_max`
- 单区域模式必须被视为合法退化情形

## D-07: 后置条件
- [ ] 区域结果可直接供 FT-006 聚合使用
- [ ] 不同插件输出共享同一合同结构

## D-08: 副作用
- 产出区域元数据
- 为 CLI 与 Web 提供可切换的区域模式能力

## D-09: 性能要求
- 插件选择与合同校验目标耗时应小于 `20ms`
- 区域完整覆盖与不重叠校验应与区域数线性相关

## D-10: 安全要求
- 只允许注册白名单插件模式：`equal_width`、`adaptive_volatility`
- 禁止通过动态字符串加载任意未注册插件

## D-11: 并发要求
- 插件注册表必须是只读或初始化后不可变结构
- 并发选择不同插件模式时不得修改共享配置

## D-12: 数据一致性
- 同一次分析中，区域服务必须仅消费同一条 `micro_axis`
- 插件返回的区域集合必须完整覆盖价格轴且互不重叠
- 校验失败时不得向下游返回部分区域结果

## D-13: 可观测性
- 记录 `partition_mode`、区域数量、校验耗时和失败错误码
- 对 `REGION_GAP_DETECTED`、`REGION_OVERLAP_DETECTED` 做明确日志记录

## D-14: 部署约束
- 区域服务作为核心计算层内部编排组件部署
- 不独立暴露网络接口，不依赖外部插件市场或远程配置
