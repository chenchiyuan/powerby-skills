# 交付完成确认报告（模板）

> 填写提示：用实际内容替换所有 {占位符}。所有结论必须引用 R/A/I 编号与证据位置。

## 1. 阶段判定与本次任务确认
- 阶段：{P0/P1/P2/P3/P4}
- 本次任务：{一句话}
- 已收到材料清单：{列表}
- 缺失材料清单（最小补充集）：{列表}

## 2. 目标对齐（G/C/H/K）
- 目标清单（G-xxx）
- 约束/宪法/原则清单（C-xxx）
- 假设清单（H-xxx，待确认）
- 成功指标与阈值（K-xxx，含默认建议待确认项）

## 3. 计划确认（Batch 选择 + 最小输入 + 风险依赖）
- 本次选择的 Batch
- 每个 Batch 的最小输入
- 风险与依赖（阻塞项优先）

## 4. Task 看板（Mermaid）+ Task 卡片
- Mermaid 看板
- Task 卡片列表（按优先级与依赖顺序）

## 5. 逐步实施记录（逐 Task）
- Task ID
- 执行结果：Pass / Fail / Blocked
- 问题分类：缺失 / 漂移 / 不一致 / 风险
- 修复建议（最小变更）
- 验收方式
- 证据位置

## 6. 完成确认包（DoD 对照 + 证据链）
- DoD 对照表（逐条：满足/部分/不满足 + 证据）
- 追溯矩阵增量更新（R/A/I）
- 未完成项与处置建议
- 下一批次进入条件

## 7. 引用与证据链
- 标准与资料引用列表（说明用途）
- 证据索引（R-xxx/A-xxx/I-xxx 对应路径/段落/commit）
