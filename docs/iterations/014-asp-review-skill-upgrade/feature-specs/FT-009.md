# FT-009: 归档体系

## 基本信息
- **Feature ID**: FT-009
- **功能名称**: 归档体系
- **对应需求**: REQ-015, REQ-016, REQ-017, REQ-018
- **功能类型**: 持久化
- **优先级**: 必须
- **状态**: 待实现

## D-01: 功能标识
- **Feature ID**: FT-009
- **入口类型**: Output System
- **入口路径**: `{stage}_logs/` 目录

## D-02: 输入规格
| 参数名 | 类型 | 必填 | 约束 | 默认值 | 示例 |
|--------|------|------|------|--------|------|
| stage | string | 是 | 5 个阶段之一 | - | "product" |
| round | integer | 是 | >= 1 | - | 1 |
| reviewer | string | 是 | Claude/Codex | - | "Claude" |
| report_content | object | 是 | 符合统一模板 | - | - |

## D-03: 前置条件
- 审查已完成
- 报告内容符合统一模板

## D-04: 正常输出
- 审查报告文件：`{stage}_logs/round-{N}-{reviewer}.md`
- 修复指令文件：`{stage}_logs/round-{N}-fix-instructions.yaml`（可选）
- 复审记录文件：`{stage}_logs/round-{N}-review-result.md`（可选）

## D-05: 异常行为
| 错误码 | 触发条件 | 行为 |
|--------|---------|------|
| ERR-ARCH-001 | 目录不存在 | 自动创建目录 |
| ERR-ARCH-002 | 文件已存在 | 覆盖写入并记录警告 |

## D-06: 边界值
- Round = 1 → 首次审查，无历史记录
- Round > 3 → 应包含 ESCALATE 标记

## D-07: 后置条件
- 审查报告已持久化
- 可被后续轮次读取
- 可被编排器解析

## D-08: 副作用
- 创建或追加 `{stage}_logs/` 目录
- 写入文件到文件系统

## D-17: Test Oracle
**业务规则**:
- 所有阶段报告遵循统一模板
- 文件命名符合 `round-{N}-{reviewer}.md` 格式
- 报告必须包含 Reviewer、Round、Stage、Status 字段

**成功输出 Schema**:
```yaml
report_file:
  path: string  # {stage}_logs/round-{N}-{reviewer}.md
  content:
    reviewer: string
    round: integer
    stage: enum [product, spec, architecture, plan, implementation]
    audit_date: date
    status: enum [PASS, FAIL, ESCALATED]
    alignment_summary: object
    findings: array
```

## D-12: 数据一致性

## D-13: 可观测性
