# FT-004: orchestrator 状态通知

## 基本信息
- **Feature ID**: FT-004
- **功能名称**: orchestrator 状态通知
- **对应需求**: F-004
- **功能类型**: 调度层
- **优先级**: 必须（P0）
- **状态**: 待实现

## D-01: 功能标识
- **Feature ID**: FT-004
- **入口类型**: Skill（orchestrator 内部能力）
- **入口路径**: `skills/pb-v1-orchestrator/SKILL.md`

## D-02: 输入规格
| 参数名 | 类型 | 必填 | 约束 | 默认值 | 示例 |
|--------|------|------|------|--------|------|
| event_type | enum | 是 | completed/fail/gate_hit/flow_done | - | "completed" |
| skill_name | string | 是 | pb-v1-* skill 名称 | - | "pb-v1-drafting" |
| next_skill | string | 否 | 下一个 skill 名称（正常推进时） | - | "pb-v1-reviewer" |
| gate | object | 否 | Gate 命中信息（gate_hit 时） | - | { type: "G3", question: "Redis vs Memcached" } |
| review_detail | object | 否 | reviewer 结果详情（fail 时） | - | { type: "PRD", issue_count: 3, auto_fixable: true } |

## D-03: 前置条件
- orchestrator 已完成一次 agent 调度并收到结果
- 或流程已完成

## D-04: 正常输出
5 种通知格式，直接输出到用户对话：

| 场景 | 格式 |
|------|------|
| 正常推进 | `✅ {skill} 完成 → 自动推进到 {next_skill}` |
| reviewer PASS | `✅ reviewer({type}) PASS → 自动推进到 {next_skill}` |
| reviewer FAIL + 自动回流 | `🔄 reviewer({type}) FAIL（{n} 个问题，均可自动修复）→ 回流 {skill}` |
| Gate 命中 | `⛔ Gate {G1-G5}: {问题描述}` + 选项列表 + "需要你决定: {问题}" |
| 流程完成 | `🏁 流程完成` |

## D-05: 异常行为
| 错误码 | 触发条件 | 行为 | 错误消息 |
|--------|---------|------|---------|
| ERR-NOTIFY-001 | event_type 不在枚举范围 | 降级为通用通知 | "ℹ️ {skill}: {raw_status}" |
| ERR-NOTIFY-002 | Gate 命中但缺少问题描述 | 输出通用 Gate 通知 | "⛔ Gate {type} 命中，请确认后续方向" |

## D-06: 边界值
- reviewer FAIL 且 issue_count = 0 → 异常，降级为通用通知
- Gate 命中且选项为空 → 输出开放式问题，不提供选项
- 连续多个 Skill 快速完成 → 每个都输出独立通知，不合并

## D-07: 后置条件
- 用户已收到状态通知文本
- 通知内容与 flow-state.md 中的状态一致

## D-08: 副作用
- 向用户对话输出文本（不可撤回）
- 不修改任何文件

## 架构维度

### D-09: 性能要求
- 通知输出延迟：即时（文本输出，无 I/O）

### D-10: 安全约束
- 通知不含敏感信息
- Gate 命中通知不泄露内部实现细节

### D-11: 幂等性
- 通知是副作用操作（输出到对话），不可撤回，不要求幂等

### D-12: 事务性
- 不适用（纯文本输出）

### D-13: 可观测性
- 通知本身即可观测输出
- Gate 命中通知同时记录到 flow-state.md

### D-14: 降级策略
- event_type 不在枚举范围 → 降级为通用通知格式

### D-15: 依赖关系
- **上游**: completion_signal（触发通知）
- **上游**: orchestrator Gate 判断结果
- **下游**: 用户（接收通知）
- **Feature 依赖**: FT-002（调度器产生事件）、FT-005（回流判断产生事件）

### D-16: 实现映射
- **入口文件**: skills/pb-v1-orchestrator/SKILL.md（内嵌能力）
- **实现方式**: orchestrator 在每次 agent 返回后输出格式化文本
- **变更类型**: NEW（orchestrator 新增能力）
