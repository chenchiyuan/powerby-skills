## D-01: 功能标识

- **入口类型**: 区域插件实现
- **入口路径**: `adaptive_volatility_plugin`, `equal_width_plugin`

## D-02: 输入规格
| 参数名 | 类型 | 必填 | 约束 | 默认值 | 示例 |
|--------|------|------|------|--------|------|
| micro_axis | object | 是 | 来自 FT-002 的完整价格轴 | - | 100 个价格单元 |
| candles | array<object> | 是 | 仅 `adaptive_volatility` 需要访问 OHLCV 波动信息 | - | 1000 根 K 线 |
| plugin_mode | string | 是 | `adaptive_volatility` 或 `equal_width` | - | `equal_width` |
| group_size | integer | 否 | `equal_width` 模式下每组包含的 `micro bins` 数 | `5` | `5` |
| atr_period | integer | 否 | `adaptive_volatility` 模式下用于计算最新 ATR 的周期，必须 `>= 2` | `20` | `20` |

## D-03: 前置条件
- [ ] 已选择具体区域插件模式
- [ ] `equal_width` 模式下 `group_size >= 1`
- [ ] `adaptive_volatility` 模式下存在可用于估计最新 `ATR(atr_period)` 的 OHLCV 数据

## D-04: 正常输出
- `equal_width` 模式按固定组宽切分区域，默认每 `5` 个 `micro bins` 组成一个区域，尾组覆盖剩余部分
- `adaptive_volatility` 模式按以下唯一规则切分区域：
  - 计算 `micro_bin_width = (price_max - price_min) / micro_bins`
  - 基于输入 K 线计算最新 `ATR(atr_period)`，一期默认 `atr_period = 20`
  - 计算 `adaptive_group_size = max(1, round(ATR(atr_period) / micro_bin_width))`
  - 按 `adaptive_group_size` 顺序切分 `micro bins`，最后一组覆盖剩余部分
- 两种模式都输出统一合同结构的区域集合
- 两种模式都满足“完整覆盖历史价格范围、彼此不重叠”

## D-05: 异常行为
| 错误码 | 触发条件 | 错误消息 |
|--------|---------|---------|
| INVALID_GROUP_SIZE | `group_size < 1` | 等宽切分参数非法 |
| INVALID_ATR_PERIOD | `atr_period < 2` | ATR 周期必须大于等于 2 |
| INSUFFICIENT_VOLATILITY_CONTEXT | 自适应模式缺少足够波动上下文 | 缺少波动上下文，无法计算最新 ATR 并生成自适应区域 |
| INVALID_REGION_COUNT | 插件输出 0 个区域 | 区域插件未生成有效区域 |

## D-06: 边界值
- `equal_width` 模式下，若 `100` 个 `micro bins` 无法被 `group_size` 整除，最后一组仍必须合法覆盖剩余部分
- `adaptive_volatility` 模式下，若 `ATR(atr_period) < micro_bin_width`，则 `adaptive_group_size` 必须退化为 `1`
- `adaptive_volatility` 模式下，若 `ATR(atr_period)` 很大，`adaptive_group_size` 仍不得超过 `micro_bins`
- 两种模式都必须允许生成 1 个或多个区域

## D-07: 后置条件

- [ ] 区域输出可直接送入 FT-006 做聚合

## D-08: 副作用

## D-09: 性能要求
- `equal_width` 与 `adaptive_volatility` 单次切分目标耗时均应小于 `30ms`
- `adaptive_volatility` 的 `ATR_20` 计算必须在一次线性扫描内完成

## D-10: 安全要求
- 两类插件都只接受经过 FT-001 校验的数值输入
- 必须拒绝非法 `group_size`、`atr_period` 和空区域输出

## D-11: 并发要求
- 两类插件必须无共享可变状态
- 相同输入在并发执行下必须得到相同区域划分结果

## D-12: 数据一致性
- `equal_width` 必须稳定输出等组宽区域，尾组只覆盖剩余 `micro bins`
- `adaptive_volatility` 必须仅基于最新 `ATR(atr_period)` 与 `micro_bin_width` 推导 `adaptive_group_size`
- 两类插件都不得改变价格轴总覆盖范围

## D-13: 可观测性
- 记录 `plugin_mode`、`group_size` 或 `atr_period`、`adaptive_group_size`、区域数量与耗时
- 高低波动样本应能通过日志确认自适应组宽差异

## D-14: 部署约束
- 作为 `Region Partition Service` 的内嵌插件部署
- 一期不引入外部数值库或独立插件分发机制
