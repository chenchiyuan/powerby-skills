## D-02: 输入规格
| 参数名 | 类型 | 必填 | 约束 | 默认值 | 示例 |
|--------|------|------|------|--------|------|
| iteration_dir | string | 是 | 有效的迭代目录路径 | - | docs/iterations/015-pb-v1-flow-autoprogression/ |

## D-03: 前置条件
- 迭代目录存在
- flow-state.md 存在（否则无断点可恢复）
- 流程处于中断状态（非正常完成）

## D-04: 正常输出
向用户报告恢复评估结果：

```markdown
## 断点恢复评估

### 流程状态
- 流程类型: standard
- 中断位置: pb-v1-designing（进行中）
- 最后完成: pb-v1-reviewer(PRD) PASS

### 产物一致性检查
| 产物 | flow-state 记录 | 文件系统实际 | 一致性 |
|------|----------------|-------------|--------|
| proposal.md | ✅ 完成 | ✅ 存在 | 一致 |
| feature-specs/ | ✅ 完成 | ✅ 存在(8 个) | 一致 |
| architecture.md | 🔄 进行中 | ❌ 不存在 | 不一致 |

### 恢复建议
建议从 pb-v1-designing 重新开始（architecture.md 未生成）

### ⚠️ 需要确认
中断期间是否手动修改了以下产物？
- proposal.md
- feature-specs/*.md
```

用户确认后，orchestrator 从恢复点继续调度。

## D-05: 异常行为
| 错误码 | 触发条件 | 行为 | 错误消息 |
|--------|---------|------|---------|
| ERR-RESUME-001 | flow-state.md 不存在 | 快速失败 | "无断点可恢复: flow-state.md 不存在" |
| ERR-RESUME-002 | 流程已正常完成 | 提示无需恢复 | "流程已完成，无需恢复" |
| ERR-RESUME-003 | 产物大面积不一致（>50% 不一致） | 建议重新开始 | "产物状态严重不一致，建议从 {earliest_valid_skill} 重新开始" |

## D-06: 边界值
- flow-state.md 存在但所有 Skill 为⏳待执行 → 视为未启动，建议从 discovery 开始
- flow-state.md 记录完成但产物被删除 → 标记不一致，建议重新执行对应 Skill
- 中断发生在 reviewer 执行中 → 建议重新执行 reviewer（reviewer 无中间状态）
- 中断发生在 Refinery 回流中 → 恢复到回流前的 reviewer FAIL 状态，重新判断

## D-07: 后置条件
- 用户已收到恢复评估报告
- 用户已确认恢复点
- flow-state.md 已修正为与文件系统一致的状态
- orchestrator 可从恢复点继续调度

## D-08: 副作用
- 可能修正 flow-state.md（使其与文件系统一致）
- 不修改任何产物文档
- 不自动恢复执行（需用户确认）

## 架构维度

### D-09: 性能要求
- 状态扫描延迟：< 1s（扫描 flow-state.md + 文件系统目录）
- 无并发需求

### D-10: 安全约束
- 恢复前必须请求用户确认（中断期间用户可能手动修改产物）
- 不自动恢复执行

### D-11: 幂等性
- 恢复评估是幂等的：同一状态下重复扫描产生相同评估结果

### D-12: 事务性
- flow-state.md 修正是原子写入
- 不修改任何产物文档

### D-13: 可观测性
- 恢复评估报告输出到用户对话
- 产物一致性检查结果可审计

### D-14: 降级策略
- flow-state.md 不存在 → 快速失败（无断点可恢复）
- 产物大面积不一致（>50%）→ 建议从最早有效节点重新开始

### D-15: 依赖关系
- **上游**: flow-state.md（扫描状态）
- **上游**: 文件系统（验证产物存在性）
- **下游**: orchestrator（从恢复点继续调度）
- **下游**: 用户（确认恢复点）

### D-16: 实现映射
- **入口文件**: skills/pb-v1-resume/SKILL.md（待新建）
- **实现方式**: 全新 Skill，扫描 + 对比 + 报告 + 确认
- **变更类型**: NEW
- **优先级**: P1（Phase 3 实施）
