## D-06: 边界值
- 所有测试字段完整 → 无 issue
- 缺少 D-17 或 D-18 → MAJOR
- 缺少 D-19 或 D-20 → MINOR

## D-07: 后置条件
- 测试化检查结果已生成
- 可被写入审查报告的 Findings 部分

## D-08: 副作用
- 无副作用（只读检查）

## D-17: Test Oracle
**业务规则**:
- D-17（Test Oracle）缺失或弱化 → MAJOR
- D-18（Fixture Contract）缺失或弱化 → MAJOR
- D-19（Test Case Groups）缺失 → MINOR
- D-20（Coverage Claim）缺失 → MINOR

**弱化定义**:
- D-17 没有明确的业务规则或成功输出 Schema
- D-18 没有最小数据集或 Mock 策略
- D-19 测试组数 < 2
- D-20 没有具体的覆盖率声明

## D-18: Fixture Contract
**最小数据集**:
- 完整的功能规格卡（包含 D-17~D-20）
- 不完整的功能规格卡（缺少部分测试字段）
- 弱化的功能规格卡（测试字段存在但内容不足）

**Mock 策略**:
- 不 mock 文件读取
- 使用真实的功能规格卡进行测试

## D-19: Test Case Groups
| 测试组 | 用例数 | 优先级 |
|--------|--------|--------|
| 完整性检查 | 4 | P0 |
| 弱化检测 | 4 | P0 |
| 严重度判定 | 4 | P0 |

## D-20: Coverage Claim
