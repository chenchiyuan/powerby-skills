# FT-006: 区域聚合、热力图与诊断输出

## 基本信息
- **Feature ID**: FT-006
- **功能名称**: 区域聚合、热力图与诊断输出
- **对应需求**: REQ-007, REQ-008
- **功能类型**: orchestration
- **优先级**: P0
- **状态**: draft

---

## D-01: 功能标识
- **全局唯一 ID**: FT-006
- **入口类型**: 结果聚合与输出整形
- **入口路径**: `acceptance_map_aggregator`

## D-02: 输入规格
| 参数名 | 类型 | 必填 | 约束 | 默认值 | 示例 |
|--------|------|------|------|--------|------|
| micro_probabilities | array<object> | 是 | 来自 FT-003 的底层概率分布 | - | 100 个价格单元结果 |
| regions | array<object> | 是 | 来自 FT-004 / FT-005 的区域集合 | - | 20 个区域 |
| coverage_sources_by_bin | array<array<integer>> | 条件必填 | 当 `include_diagnostics = true` 时必须提供，且长度与 `micro_probabilities` 一致 | - | `[[0], [0,1], []]` |
| include_heatmap | boolean | 否 | 是否返回底层热力图数据 | `true` | `true` |
| include_diagnostics | boolean | 否 | 是否返回诊断字段 | `true` | `true` |

## D-03: 前置条件
- [ ] 底层概率分布已归一化
- [ ] 区域集合已通过完整覆盖与不重叠校验
- [ ] 区域边界与底层价格轴属于同一坐标系
- [ ] 若启用诊断字段，则已提供与 `micro bins` 对齐的 `coverage_sources_by_bin`

## D-04: 正常输出
- 返回可视化热力图所需的底层价格概率数据
- 返回区域级结果列表
- 区域级结果至少包含：
  - `region_id`
  - `lower_bound`
  - `upper_bound`
  - `price_acceptance_probability`
- 若启用诊断字段，还需包含：
  - `coverage_count`
  - `weighted_volume_contribution`
- 返回按概率由高到低排序的区域列表

## D-05: 异常行为
| 错误码 | 触发条件 | 错误消息 |
|--------|---------|---------|
| INVALID_PROBABILITY_SUM | 底层概率和不为 1 | 底层价格接受度概率未归一化 |
| REGION_AXIS_MISMATCH | 区域边界与价格轴不一致 | 区域集合与底层价格轴不匹配 |
| EMPTY_REGION_RESULT | 聚合后无有效区域 | 区域聚合结果为空 |
| MISSING_DIAGNOSTIC_CONTEXT | 请求诊断字段但缺少覆盖来源上下文 | 缺少诊断上下文，无法生成区域级 coverage_count |

## D-06: 边界值
- 单区域结果必须合法输出
- 所有区域概率和必须为 1
- 诊断字段关闭时，不得输出对应字段
- 热力图关闭时，不得输出底层价格单元列表

## D-07: 后置条件
- [ ] CLI 可直接序列化聚合结果
- [ ] Web 可直接渲染热力图和区域列表

## D-08: 副作用
- 产出最终分析结果对象
- 影响人类可读和程序可消费的展示层

## D-09: 性能要求
- 在 `100` 个底层价格单元、`20` 个区域内，聚合目标耗时应小于 `50ms`
- 区域概率求和误差应控制在 `1e-6` 以内

## D-10: 安全要求
- 只聚合来自本系统内部的标准化概率分布与区域集合
- 若输入结果未归一化或区域越界，必须快速失败而非返回部分结果

## D-11: 并发要求
- 聚合器必须保持无状态，可并发处理多个分析结果
- 诊断字段开关不得影响同批次请求的其他结果对象

## D-12: 数据一致性
- 区域级 `price_acceptance_probability` 必须完全来源于底层价格单元聚合
- `coverage_count` 与 `weighted_volume_contribution` 必须与相同区域边界对齐
- `heatmap` 与 `regions` 必须共享同一条价格轴坐标系

## D-13: 可观测性
- 记录区域数、热力图开关、诊断字段开关、聚合耗时
- 当发生 `INVALID_PROBABILITY_SUM` 或 `REGION_AXIS_MISMATCH` 时记录完整错误上下文

## D-14: 部署约束
- 聚合器与序列化器部署在同一分析核心包中
- 不依赖数据库、缓存或外部搜索服务
