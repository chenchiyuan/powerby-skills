# 交付物模板

> 每个 Gate 需要交付的内容。只要求回答这些问题，不限格式。

---

## Gate 1 交付物：需求范围

### 必须回答的问题

1. 这个需求要解决什么问题？用户现在的痛点是什么？
2. P0 功能有哪些？（去掉它核心任务就无法完成的）
3. P1 功能有哪些？（重要但可以后排的）
4. 明确不做什么？
5. 关键流程走查：用户从哪进来 → 每一步看到什么、做什么 → 最终到哪？
   - 优先用参照物截图串联，标注差异
   - 没有合适参照物时用 ASCII 草图
6. 有哪些不确定的地方需要老板确认？

---

## Gate 2 交付物：技术方案 + 任务计划

### 技术方案——必须回答的问题

1. 现有代码中有哪些可以复用的？
2. 方案 A 是什么？优点、缺点各是什么？
3. 方案 B 是什么？优点、缺点各是什么？
4. 你推荐哪个？为什么？
5. 有哪些关键决策需要老板拍板？（技术选型、架构变更、第三方依赖等）

### 任务计划——必须回答的问题

每个任务回答：
1. 做什么？
2. 做到什么程度算完？（具体的验收标准，不是"完成 XX 功能"）
3. 依赖哪个任务？（没有依赖就写"无"）
4. 优先级？（P0 / P1）

---

## Gate 3 交付物：自检报告

### 必须回答的问题

对照 Gate 1 的 P0 功能清单，逐项回答：

| P0 功能 | 是否实现 | 正常流程测试结果 | 异常流程测试结果 | 备注 |
|---------|---------|----------------|----------------|------|
| （逐项列出） | 是/否 | 通过/未通过 | 通过/未通过 | （问题说明） |

额外回答：
1. 有没有计划外的变更？如果有，是什么、为什么？
2. 有没有已知的遗留问题？如果有，影响范围是什么？
3. 能否现场演示核心流程？
