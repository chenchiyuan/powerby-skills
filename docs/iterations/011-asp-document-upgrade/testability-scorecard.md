## 3. 指标计算明细

### M-01 功能闭合集合完成率
- 公式：已完成规格卡数 / 总功能数
- 计算：15/15 = 100%
- 说明：所有 15 个功能均有独立规格卡

### M-02 原子功能率
- 公式：原子功能数 / 总功能数
- 计算：15/15 = 100%
- 说明：每个功能职责单一，无需进一步拆分

### M-03 Oracle 完整率
- 公式：有 D-17 Oracle 的功能数 / 总功能数
- 计算：15/15 = 100%
- 说明：所有功能均定义了 Test Oracle（成功输出 Schema + 业务规则）

### M-04 Fixture 完整率
- 公式：有 D-18 Fixture 的功能数 / 总功能数
- 计算：15/15 = 100%
- 说明：所有功能均定义了 Fixture Contract（最小数据集 + Mock 策略）

### M-05 测试追踪完整率
- 公式：REQ→Feature 覆盖率
- 计算：15/15 = 100%
- 说明：所有 REQ 均有对应 Feature

### M-06 规则负向覆盖率
- 公式：有 D-05 异常行为定义的功能数 / 总功能数
- 计算：15/15 = 100%
- 说明：所有功能均定义了异常行为（错误码 + 触发条件 + 错误消息）

### M-07 覆盖宣称可信率
- 公式：D-20 允许覆盖声明的功能数 / 总功能数
- 计算：1/15 = 6.7%
- 说明：仅 FT-014（8 组测试）达到 Test Ready 标准。其余功能测试组数 < 8，产品阶段属于正常状态，架构阶段补充后将提升
