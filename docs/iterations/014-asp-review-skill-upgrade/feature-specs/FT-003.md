# FT-003: Alignment Summary 前置机制

## 基本信息
- **Feature ID**: FT-003
- **功能名称**: Alignment Summary 前置机制
- **对应需求**: REQ-004
- **功能类型**: 核心能力
- **优先级**: 必须
- **状态**: 待实现

## D-01: 功能标识
- **Feature ID**: FT-003
- **入口类型**: Skill Internal Function
- **入口路径**: `skills/pb-review-v2/` (内部函数)

## D-02: 输入规格
| 参数名 | 类型 | 必填 | 约束 | 默认值 | 示例 |
|--------|------|------|------|--------|------|
| current_doc | object | 是 | 当前审查文档 | - | proposal.md 内容 |
| upstream_docs | array | 是 | 上游文档列表 | - | [design-brief.md] |
| stage | string | 是 | 当前阶段 | - | "product" |

## D-03: 前置条件
- 当前文档已读取
- 上游文档已读取（如存在）

## D-04: 正常输出
```yaml
alignment_summary:
  upstream_complete: boolean  # 上游定义是否完整覆盖
  downstream_clean: boolean   # 当前文档是否无溢出
  gaps: array                 # 缺口清单
    - type: enum [missing, overflow, conflict]
      description: string
      evidence: string
  status: enum [PASS, FAIL]
```

## D-05: 异常行为
| 错误码 | 触发条件 | 行为 |
|--------|---------|------|
| ERR-ALIGN-001 | 文档解析失败 | 返回 FAIL |

## D-06: 边界值
- 无上游文档 → upstream_complete=true (无需对齐)
- 空文档 → FAIL

## D-07: 后置条件
- Alignment Summary 已生成
- 可被写入审查报告

## D-08: 副作用
- 无副作用（只读操作）

## D-17: Test Oracle
**业务规则**:
- 未通过对齐时，Status 不能为 PASS
- gaps 数组必须包含具体证据

## D-18: Fixture Contract
**最小数据集**:
- proposal.md + design-brief.md (对齐场景)
- proposal.md 无 design-brief.md (无上游场景)

## D-19: Test Case Groups
| 测试组 | 用例数 | 优先级 |
|--------|--------|--------|
| 对齐通过 | 2 | P0 |
| 缺口检测 | 3 | P0 |
| 溢出检测 | 2 | P0 |

## D-20: Coverage Claim
- **对齐检查覆盖**: 100%

## D-09: 性能要求
- **响应时间**: 对齐检查 < 30 秒（取决于文档大小）
- **吞吐量**: 单次调用
- **资源消耗**: 中等（需要读取和比较多个文档）

## D-10: 安全要求
- **数据隐私**: 不上传用户文档
- **权限控制**: 只读取迭代目录中的文档
- **输入验证**: 验证文档存在性和格式

## D-11: 并发要求
- **并发模式**: 无并发需求
- **冲突处理**: 不适用

## D-12: 数据一致性
- **幂等性**: 同一文档集重复检查产生相同结果
- **一致性保证**: 对齐结果与文档实际内容一致

## D-13: 可观测性
- **日志**: Alignment Summary 写入审查报告
- **追踪**: 通过 gaps 数组追踪具体缺口

## D-14: 部署约束
- **运行环境**: Claude Code CLI
- **依赖**: 无外部依赖

## D-15: 依赖关系
- **上游依赖**: FT-002（阶段识别，提供上游链映射）
- **下游依赖**: FT-001（核心框架，消费对齐结果）
- **Feature 依赖**: FT-002

## D-16: 实现映射
- **入口文件**: `skills/pb-review-v2/SKILL.md`（Workflow 第 3 步）
- **核心逻辑**: 基于阶段的上游链映射表做覆盖检查
- **配置文件**: 无（对齐链映射内建于 architecture.md 第 2.2.2 节）
