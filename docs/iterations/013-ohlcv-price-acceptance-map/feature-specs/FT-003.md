- **对应需求**: REQ-003, REQ-004
- **功能类型**: domain
- **优先级**: P0

## D-01: 功能标识
- **全局唯一 ID**: FT-003
- **入口类型**: 核心概率计算
- **入口路径**: `price_acceptance_engine`

## D-02: 输入规格
| 参数名 | 类型 | 必填 | 约束 | 默认值 | 示例 |
|--------|------|------|------|--------|------|
| candles | array<object> | 是 | 已通过 FT-001 校验 | - | 1000 根 K 线 |
| micro_axis | object | 是 | 已通过 FT-002 构建 | - | 100 个价格单元 |
| time_decay_mode | string | 是 | 一期仅实现 `exponential` | `exponential` | `exponential` |
| decay_lambda | number | 是 | 有限数值且 `> 0` | 由配置给定 | `0.004` |
| zero_volume_policy | string | 否 | 一期默认 `keep_zero_contribution` | `keep_zero_contribution` | `keep_zero_contribution` |

## D-03: 前置条件
- [ ] 输入 K 线已标准化
- [ ] 底层价格轴已构建
- [ ] 时间衰减模式与参数已确定

## D-04: 正常输出
- 返回每个 `micro bin` 的 `price_acceptance_probability`
- 返回每个 `micro bin` 的 `weighted_volume_contribution`
- 返回每个 `micro bin` 的 `coverage_count`
- 保证全部 `price_acceptance_probability` 归一化后总和为 1

## D-05: 异常行为
| 错误码 | 触发条件 | 错误消息 |
|--------|---------|---------|
| UNSUPPORTED_DECAY_MODE | 非一期支持的衰减模式 | 当前版本仅支持指数衰减时间权重 |
| INVALID_DECAY_LAMBDA | `decay_lambda <= 0` | 指数衰减参数必须大于 0 |
| EMPTY_COVERAGE_SET | 某根合法 K 线未覆盖任何价格单元 | 价格轴覆盖异常，存在未被映射的 K 线 |
| ZERO_TOTAL_WEIGHT | 所有 K 线贡献累加后为 0 | 总权重为 0，无法归一化价格接受度概率 |

## D-06: 边界值
- `volume = 0` 的 K 线允许存在，但其贡献为 0
- `high = low` 的十字 K 线必须能被映射到至少一个价格单元
- 最新 K 线必须拥有最大时间权重
- 当单根 K 线覆盖多个价格单元时，其 `time_weight * volume` 必须按覆盖单元数均匀分配

## D-07: 后置条件
- [ ] 产出一组可聚合到区域层的底层概率分布
- [ ] 时间衰减与成交量影响已反映到结果中

## D-08: 副作用
- 生成底层概率引擎元数据
- 为区域聚合、CLI JSON 和热力图提供统一基础分布

## D-09: 性能要求
- 在 `1000` 根 K 线、`100` 个 `micro bins` 下，核心计算目标耗时应小于 `200ms`
- 概率归一化完成后总和误差应控制在 `1e-6` 以内

## D-10: 安全要求
- 只处理数值型价格与成交量，不执行输入中的动态表达式
- 对异常衰减参数必须快速失败并返回确定性错误码

## D-11: 并发要求
- 概率引擎必须保持无状态，可并发分析多个交易对
- 不允许使用共享累加器跨请求复用结果

## D-12: 数据一致性
- 所有 `price_acceptance_probability` 必须来源于同一组 K 线和同一条 `micro_axis`
- `weighted_volume_contribution` 与 `coverage_count` 必须与底层价格单元一一对应
- 任意一次分析中不得混用不同 `decay_lambda` 的中间结果

## D-13: 可观测性
- 记录 `decay_mode`、`decay_lambda`、`sample_size`、`micro_bins` 与计算耗时
- 记录 `ZERO_TOTAL_WEIGHT`、`EMPTY_COVERAGE_SET` 等关键失败错误码

## D-14: 部署约束
- 作为纯计算模块部署在 `powerby/acceptance_map/` 中
- 不依赖网络、数据库或外部数值计算服务
