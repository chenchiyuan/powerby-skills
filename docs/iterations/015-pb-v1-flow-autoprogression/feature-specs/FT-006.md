# FT-006: clarify auto_decided 分类

## 基本信息
- **Feature ID**: FT-006
- **功能名称**: clarify 新增 auto_decided 分类
- **对应需求**: F-006
- **功能类型**: 记录层
- **优先级**: 必须（P0）
- **状态**: 待实现

## D-01: 功能标识
- **Feature ID**: FT-006
- **入口类型**: Skill
- **入口路径**: `skills/pb-v1-clarify/SKILL.md`

## D-02: 输入规格
| 参数名 | 类型 | 必填 | 约束 | 默认值 | 示例 |
|--------|------|------|------|--------|------|
| decision | string | 是 | 系统做出的决策描述 | - | "选择单体部署模式" |
| rationale | string | 是 | 为什么这样选 | - | "上游约束未提及分布式需求，单体复杂度最低" |
| alternatives | array | 是 | 备选方案列表，≥ 1 | - | ["微服务部署", "Serverless"] |
| reversibility | string | 是 | 如果 reviewer 挑出问题如何回退 | - | "可逆，后续可拆微服务" |
| skill_context | string | 是 | 做出决策的 Skill 名称 | - | "pb-v1-designing" |
| iteration_path | string | 是 | 迭代目录路径 | - | "docs/iterations/015/" |

## D-03: 前置条件
- clarifications/ 目录存在（或可创建）
- 决策满足 AUTO_DECIDE_WITH_ASSUMPTION 条件：可逆、影响范围局部、不改变外部合同

## D-04: 正常输出
写入 clarifications/ 的记录，格式：

```markdown
### CLR-AUTO-{NNN}: {决策标题}
- **决策**: {选择了什么}
- **理由**: {为什么这样选}
- **备选**: {还有什么其他选择}
- **可逆性**: {如果 reviewer 挑出问题，如何回退}
- **来源分类**: auto_decided
- **决策 Skill**: {做出决策的 Skill}
- **状态**: 生效
- **决策时间**: {ISO8601}
```

同时更新 clarifications/index.md 索引。

## D-05: 异常行为
| 错误码 | 触发条件 | 行为 | 错误消息 |
|--------|---------|------|---------|
| ERR-CLR-001 | 缺少必填字段（rationale/alternatives/reversibility） | 拒绝记录 | "auto_decided 记录不完整，缺少: {fields}" |
| ERR-CLR-002 | CLR-AUTO 编号冲突 | 自动递增到下一个可用编号 | 静默处理 |
| ERR-CLR-003 | 决策实际不可逆但标记为可逆 | 无法自动检测，依赖 reviewer 审计 | - |

## D-06: 边界值
- 首条 auto_decided 记录 → CLR-AUTO-001
- 同一 Skill 同一轮次多条决策 → 各自独立编号
- alternatives 为空数组 → ERR-CLR-001（必须至少有 1 个备选）
- 与已有 user_confirmed 记录冲突 → 标注冲突，不覆盖（user_confirmed 优先级更高）

## D-07: 后置条件

- clarifications/index.md 已更新

## D-08: 副作用

## 架构维度

### D-09: 性能要求
- 记录写入延迟：< 100ms（本地文件系统）

### D-10: 安全约束
- auto_decided 记录不含敏感信息
- 记录不可被静默删除（reviewer 审计依赖）

### D-11: 幂等性
- 同一决策重复写入 → 编号自动递增，不覆盖已有记录

### D-12: 事务性
- 单文件写入 + index 更新，两步操作非原子但可恢复（index 可重建）

### D-13: 可观测性
- clarifications/index.md 提供全局索引
- reviewer 可通过 source_classification: auto_decided 筛选审计

### D-14: 降级策略
- clarifications/ 目录不存在 → 自动创建
- index.md 损坏 → 基于目录内文件重建

### D-15: 依赖关系
- **上游**: orchestrator 或 agent 的 AUTO_DECIDE_WITH_ASSUMPTION 决策
- **下游**: reviewer（审计 auto_decided 记录）
- **下游**: flow-state.md 假设记录区块（索引引用）
- **平行**: clarify 现有 user_confirmed / model_inferred 记录共存

### D-16: 实现映射
- **入口文件**: skills/pb-v1-clarify/SKILL.md
- **核心变更**: source_classification 枚举新增 auto_decided，记录格式新增 决策Skill/可逆性 字段
- **变更类型**: MODIFIED（扩展现有分类）
