# FT-002: Micro Price Axis 构建

## 基本信息
- **Feature ID**: FT-002
- **功能名称**: Micro Price Axis 构建
- **对应需求**: REQ-002
- **功能类型**: domain
- **优先级**: P0
- **状态**: draft

---

## D-01: 功能标识
- **全局唯一 ID**: FT-002
- **入口类型**: 底层价格轴构建
- **入口路径**: `micro_axis_builder`

## D-02: 输入规格
| 参数名 | 类型 | 必填 | 约束 | 默认值 | 示例 |
|--------|------|------|------|--------|------|
| price_min | number | 是 | 取自合法输入中的历史最低价 | - | `61234.1` |
| price_max | number | 是 | 取自合法输入中的历史最高价 | - | `73455.9` |
| micro_bins | integer | 是 | `>= 10`，一期默认 `100` | `100` | `100` |
| axis_mode | string | 否 | 一期仅锁定 `fixed_count` | `fixed_count` | `fixed_count` |

## D-03: 前置条件
- [ ] `price_max > price_min`
- [ ] 输入 OHLCV 已完成合法性校验
- [ ] `micro_bins` 为有效正整数

## D-04: 正常输出
- 返回完整 `micro price axis`
- 生成 `micro_bins` 个连续、互不重叠的价格单元
- 所有价格单元完整覆盖 `[price_min, price_max]`
- 输出每个价格单元的 `lower_bound`、`upper_bound`、`center_price`

## D-05: 异常行为
| 错误码 | 触发条件 | 错误消息 |
|--------|---------|---------|
| INVALID_AXIS_RANGE | `price_max <= price_min` | 历史价格范围非法，无法构建价格轴 |
| INVALID_BIN_COUNT | `micro_bins < 10` 或非整数 | micro_bins 必须是大于等于 10 的整数 |
| UNSUPPORTED_AXIS_MODE | 非 `fixed_count` 模式被要求为一期默认实现 | 当前版本不支持该价格轴构建模式 |

## D-06: 边界值
- `micro_bins = 100` 作为一期默认值必须可稳定工作
- 第一段价格单元必须包含 `price_min`
- 最后一段价格单元必须包含 `price_max`
- 当 `price_max - price_min` 很小但非零时，仍必须产出完整价格轴

## D-07: 后置条件
- [ ] 后续概率引擎可按价格单元索引进行分配
- [ ] 价格轴可直接供热力图与区域聚合使用

## D-08: 副作用
- 产出全局价格轴元数据
- 为区域服务提供统一基础坐标系

## D-09: 性能要求
- 在合法输入范围内构建 `100` 个 `micro bins` 的目标耗时应小于 `10ms`
- 构建过程不得依赖 K 线条数做额外重复扫描

## D-10: 安全要求
- 价格轴构建只接受经过 FT-001 校验的数值边界
- 必须拒绝 `NaN`、无穷值或逆序价格范围

## D-11: 并发要求
- 价格轴构建必须是纯函数式、无共享状态
- 多个交易对并行构建时不得互相污染边界值

## D-12: 数据一致性
- `price_min` 与 `price_max` 必须与 FT-001 输出的标准化结果一致
- `micro_axis` 中每个 bin 的边界必须连续、无缺口、无重叠
- 任一价格只能归属于唯一价格单元

## D-13: 可观测性
- 记录 `price_min`、`price_max`、`micro_bins`、`axis_mode` 与构建耗时
- 当轴构建失败时记录 `INVALID_AXIS_RANGE` 或 `INVALID_BIN_COUNT`

## D-14: 部署约束
- 作为分析核心纯计算组件部署，不依赖网络或持久化层
- 必须可被概率引擎和区域服务同时复用
